# Three.js mushroom bag exports

Transparent PNG renders of the procedural mushroom bag used in the website's interactive Three.js scene.

- `threejs-mushroom-bag-fruiting-front.png` — fruiting bag, front view, 936 × 2230
- `threejs-mushroom-bag-fruiting-three-quarter.png` — fruiting bag, three-quarter view, 958 × 2230
- `threejs-mushroom-bag-bare-front.png` — bag without visible mushrooms, front view, 806 × 2230
- `threejs-mushroom-bag-bare-three-quarter.png` — bag without visible mushrooms, three-quarter view, 784 × 2230

Every file uses RGBA transparency and includes 80 pixels of clear padding around the rendered object. They can be uploaded directly to Canva.
