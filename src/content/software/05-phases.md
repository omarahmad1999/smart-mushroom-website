### What it does

Defines how the Mushroom Hub should behave during different growth stages.

### How it works

Configuration tables in the database contain environmental targets and operating rules for phases such as **incubation** and **fruiting**. The active phase is changed manually in the database.

### Output / Destination

Provides rules and target values to the controllers and scheduled services.
